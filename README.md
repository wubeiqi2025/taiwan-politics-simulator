# 台湾政治模拟器

基于 Preact、Vite、D3 与 SVG 的台湾政治历史与架空模拟网页。沿用现代液态玻璃界面，提供历史日期、县市地图、议会席位、人物、选举与分支存档功能。

## 本地运行

安装 Node.js 20.19 或更新版本，在项目目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5178
```

浏览器打开 http://localhost:5178/ 。

## 构建

```sh
npm run build
npm run preview
```

生成的 dist/index.html 为内嵌资源的单文件页面。dist 和 node_modules 不提交到仓库。

## 目录

- src：界面、核心逻辑、地图和已经整理的数据。
- raw：数据构建所需的原始资料与下载缓存。
- tools：采集、整理和检查数据的脚本。

已有 raw 数据可以通过 npm run data 重新生成 src/data。原始资料来自中选会、立法院及项目中注明的其他来源；部分历史资料有待核实，以界面资料标记为准。

## 截图与导出

县市政治详情支持多县市合图，议会席位支持最多三个议会合图。导出人物支持县市首长、当前日期重要人物和人物库勾选，人物卡片采用紧凑布局。

强制保持比例开启后，全部选中内容缩放到指定画幅；关闭时按内容延长。PNG、打印版、展示版和离线 HTML 保存页面使用相同选项。
