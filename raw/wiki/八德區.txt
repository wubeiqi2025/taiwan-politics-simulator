'''八德區'''，舊稱「八塊厝」，位於[[中華民國]][[桃園市]]東北部，為[[國防部高等軍事法院]]與[[國防部北部地方軍事法院]]所在地。北鄰[[桃園區]]，東鄰[[新北市]][[鶯歌區]]，西鄰[[中壢區]]，西南連[[平鎮區]]，南接[[大溪區]]，地勢南高北低，有[[茄苳溪 (桃園市東)|茄苳溪]]貫穿南北。行政區域東西長6,760公尺，南北長8,460公尺，面積33.7111平方公里，是桃園市面積最小的行政區<ref>{{Cite web |url=https://www.tycg.gov.tw/ch/home.jsp?id=10450&parentpath=0,10403,10449 |title=存档副本 |access-date=2022-02-07 |archive-date=2022-04-26 |archive-url=https://web.archive.org/web/20220426183537/https://www.tycg.gov.tw/ch/home.jsp?id=10450&parentpath=0%2C10403%2C10449 }}</ref>，為銜接桃園台地與台北盆地之門戶。

區內人口約有21.6萬人，人口密度每平方公里約有6,369人，為桃園市人口密度僅次於桃園區排行第二高的行政區。[[桃園縣]]於2014年12月25日升格為直轄市，原縣轄八德市改制為'''八德區'''。

== 歷史 ==
[[File:Taoyuan Canal - The Water Mill.jpg|thumb|桃園大圳八德段的水車]]
[[File:Taoyuan main Canal-3.jpg|thumb|桃園大圳在八德的水道及兩岸綠茵]]
八德區舊名「八塊厝」<ref name="八德尋根"/>（{{lang-nan-tw|tl=Peh-tè-tshù}}）（下含小字莊頭、莊尾、稻埕頭、連城、舊城、公館、租倉、城外等八處，今八德區公所、[[八德三元宮|三元宮]]一帶地區），相傳是[[清]][[乾隆]]年間有[[謝姓|謝]]、[[蕭姓|蕭]]、[[邱姓|邱]]、[[呂姓|呂]]、[[賴姓|賴]]、[[黃姓|黃]]、[[吳姓|吳]]、[[李姓]]等八戶人家至此開墾，每姓各築一屋，因而得名，另外還有客家話的稱呼八隻屋。1920年改設「-{[[八塊庄]]}-」，劃歸[[新竹州]][[桃園郡]]管轄。戰後改名[[桃園縣]]八德鄉；1995年1月「八德鄉」改制「八德市」，同時「村」改為「里」。八德區主要商業活動聚集在[[大湳 (桃園市)|大湳]]一帶，而非八德區公所所在地。2014年12月25日桃園縣改制直轄市，八德市改制「八德區」<ref name="八德尋根"/>。

=== 大事紀 ===
* 1995年，1月1日人口滿15萬，由桃園縣八德鄉改制為桃園縣八德市。
* 2010年，11月[[特力屋]]進駐八德。
* 2012年，4月14日[[巧克力共和國]]開幕。
* 2014年，5月3日[[興仁花園夜市]]於長興路開幕。11月10日，統聯1659八德（大湳）-土城（永寧）通車。12月25日，由桃園縣八德市改制為桃園市八德區。
* 2015年，1月桃拾生活廣場開幕。10月1日統聯1659改為A/B/C三線。A/B線延長至八德擴大都計介壽路二段與豐德路口（近大溪區交界）。
* 2016年，2月大湳交流道下福德一路往八德方向，將190公尺道路拓寬成10線道46米寬。12月，[[廣豐新天地]]試營運。2017年1月12日正式開幕。
* 2017年，4月茄苳路(近台一線路段)多年瓶頸由3米拓寬為8米。6月，桃園市立兒童美術館於[[廣豐新天地]]5F開幕。6月16日，位於八德擴大都計的「八德區棒壘球場」落成啟用。
* 2018年，6月20日人口突破20萬人<ref>{{Cite web |url=https://news.housefun.com.tw/news/article/164626199646.html |title=桃園升格至今人口破220萬 六都最年輕 |accessdate=2020-07-11 |archive-date=2020-07-11 |archive-url=https://web.archive.org/web/20200711223729/https://news.housefun.com.tw/news/article/164626199646.html |dead-url=no }}</ref>。8月，八德國民運動中心位在國際路與廣福路口（土地面積5,000坪）原「大湳北景雲營區」動工。9月27日桃園區延平路延伸至八德，第二期先動工（國道二號南側至和強路）長度1,150公尺，路寬20公尺。10月1日，統聯1659A/B/C移撥給桃園市政府，變更為市區公車，路線編號變更為713、715、716。10月15日桃園捷運綠線在八德擴大都計GC01標高架八德段舉辦動工典禮。11月9日延平路延伸八德第一期也動工，長度265公尺。12月位於長興路尾（[[霄裡]]與[[龍岡]]交界）的簡易綠美化公園「花舞霄裡HAKKA」落成<ref>{{Cite web |url=http://news.ltn.com.tw/news/life/breakingnews/2639736 |title=花舞霄裡HAKKA進行曲 七彩花海迎賓 |accessdate=2018-12-25 |archive-date=2020-05-25 |archive-url=https://web.archive.org/web/20200525190639/https://news.ltn.com.tw/news/life/breakingnews/2639736 |dead-url=no }}</ref>。興豐路榮興路口至八德埤塘公園之間增設約600公尺人行道。
* 2019年，1月人口密度每平方公里突破6,000人大關。2月，茄苳溪成功橋改建工程完成，橋體拓寬到長30公尺、寬8公尺。3月4日新增統聯717龍岡經大湳到永寧站班次。5月17日交通部通過三鶯線延伸桃園八德段，可行性研究報告，8月26日獲國發會同意支持<ref>{{Cite web |url=https://www.ntpc.gov.tw/ch/home.jsp?id=e8ca970cde5c00e1&dataserno=69132a474a6cc2422650f2007baea4ed |title=三鶯線延伸桃園八德段 獲國發會審查通過 |accessdate=2019-09-03 |archive-date=2020-05-25 |archive-url=https://web.archive.org/web/20200525190650/https://www.ntpc.gov.tw/ch/home.jsp?id=e8ca970cde5c00e1&dataserno=69132a474a6cc2422650f2007baea4ed |dead-url=no }}</ref>，11月13日獲行政院同意。9月6日～9月22日展出[[2019桃園地景藝術節|桃園地景藝術節]]<ref>{{Cite web |url=http://taoyuanlandart.com.tw/ |title=2019桃園地景藝術節 |access-date=2019-09-03 |archive-url=https://web.archive.org/web/20190915033412/http://taoyuanlandart.com.tw/ |archive-date=2019-09-15 |dead-url=yes }}</ref>。10月11日桃園捷運綠線GC02標地下段（八德到桃園車站地下段）舉行動工儀式<ref>{{Cite web |url=https://news.ltn.com.tw/news/life/paper/1324188 |title=桃園捷運綠線GC02標地下段開工 2026年完工 |accessdate=2019-10-12 |archive-date=2020-11-16 |archive-url=https://web.archive.org/web/20201116115751/https://news.ltn.com.tw/news/life/paper/1324188 |dead-url=no }}</ref>。10月29日國道3號增設大鶯豐德交流道獲交通部高公局審議核定。
* 2020年，1月9日與中壢區交界的桃園北區客家會館動工。8月3日桃園區延平路延伸至八德區和強路段第二期先行通車。8月7日大鶯豐德交流道獲行政院國發會同意，10月20日行政院最後確認興建。12月24日桃園區延平路延伸第一期通車(樹仁三街至國道二號橋下)。
* 2021年，9月24日八德國民運動中心試營運開幕。10月24日北區客家會館開幕。
* 2022年，3月1日由福興里分出福元里、福德里；興仁里分出興中里，全區48里改為51里。8月19日位於和強路與和平路口的八德大湳轉運站舉行動工典禮。
* 2023年，1月底人口達21萬。6月28日北二高增設八德交流道環評通過。7月19日三鶯線延伸桃園八德段環評通過。11月24日國發會通過捷運綠線延伸中壢。12月11日八德區延平路第三期工程（和強路延伸至和平路）動工。
* 2024年，1月5日，綠線高架橋下新闢道路（建德路延伸至介壽路段）動工，2月19日和強路八德轉運站啟用。
* 2025年，4月30日綠線高架橋下建德路延伸至建國路段約750公尺(德和路一段)先行通車。
* 2026年，3月1日從大和里分出大盛里，全區51里改成52里。5月11日延平路第三期通車（和強路延伸至和平路）。

根據桃園市政府民政局及桃園市八德區戶政事務所統計，2025年底八德區戶數約8.8萬戶，人口21.6萬人，區內人口最多與最少的里分別是大和里（2026年3月拆為大和里、大盛里）與大慶里，2025年底兩里人口分別為9,606人與1,604人<ref>{{Cite web |url=https://cab.tycg.gov.tw/home.jsp?id=10596&parentpath=0,10580 |title=桃園市政府民政局-人口統計 |accessdate=2020-06-28 |archive-date=2020-06-28 |archive-url=https://web.archive.org/web/20200628030123/https://cab.tycg.gov.tw/home.jsp?id=10596&parentpath=0,10580 |dead-url=no }}</ref>。

八德區居民以[[臺灣閩南人|閩南籍]]、[[臺灣客家人|客家人]]、外省眷村等為主，加上少數[[臺灣原住民族|原住民]]及[[外籍配偶 (臺灣)|外籍配偶]]等族群。另外，八德區為臺灣本島最多[[馬祖列島|馬祖]]人聚居的行政區，人數將近兩萬人，是馬祖人的新故鄉<ref>{{Cite web |url=http://tw.news.yahoo.com/%E5%85%A9%E8%80%81%E7%94%A8%E9%A6%AC%E7%A5%96%E8%A9%B1%E7%9F%AD%E6%9A%AB%E7%88%AD%E5%90%B5-%E9%84%B0%E4%B8%8D%E4%BB%A5%E7%82%BA%E6%84%8F-213000269.html |title=兩老用馬祖話短暫爭吵 鄰不以為意 |accessdate=2020-12-20 |archive-date=2019-10-11 |archive-url=https://web.archive.org/web/20191011003303/https://tw.news.yahoo.com/%E5%85%A9%E8%80%81%E7%94%A8%E9%A6%AC%E7%A5%96%E8%A9%B1%E7%9F%AD%E6%9A%AB%E7%88%AD%E5%90%B5-%E9%84%B0%E4%B8%8D%E4%BB%A5%E7%82%BA%E6%84%8F-213000269.html |dead-url=no }}</ref>。而全國規模最大的[[榮民]]就養機構—[[桃園榮民之家]]也位於該區，使八德區成為一個多元文化色彩的城市。

=== 區政組織 ===
[[File:Bade City Office, Taoyuan County 20080502.jpg|thumb|2008年5月的八德市公所（現已改制為八德區公所）]]
[[八德區公所]]是[[桃園市政府]]在八德區的派出機關，在中華民國政府架構中為市政府綜理區政的執行機關，上級業務監督機關為桃園市政府。[[区长]]由[[桃園市市長|市長]]任命，其任期為無任期保障。在區長、副區長及主任秘書之下，設有5課4室等9個內部單位<ref>{{Cite web |url=https://www.bade.tycg.gov.tw/home.jsp?id=11&parentpath=0,1,9 |title=本區介紹-本所組織介紹-組織架構圖 |publisher=桃園市政府八德區公所 |access-date=2021-09-26 |language=zh-tw |archive-date=2022-03-19 |archive-url=https://web.archive.org/web/20220319011125/https://www.bade.tycg.gov.tw/home.jsp?id=11&parentpath=0%2C1%2C9 }}</ref>。八德區為[[桃園市議會]]第三選區，在市議會的63席市議員中，八德區共選出5席區域市議員（不含平地原住民與山地原住民議員）<ref>{{Cite web |url=https://www.tycc.gov.tw/content/intro/intro_main.aspx?wtp=1&wnd=204&town=%e7%ac%ac%e4%b8%89%e9%81%b8%e5%8d%80 |title=議員介紹-本屆議員-第三選區 八德區 |publisher=桃園市議會 |access-date=2021-09-26 |language=zh-tw |archive-date=2022-03-19 |archive-url=https://web.archive.org/web/20220319011031/https://www.tycc.gov.tw/content/intro/intro_main.aspx?wtp=1&wnd=204&town=%E7%AC%AC%E4%B8%89%E9%81%B8%E5%8D%80 }}</ref>。

=== 行政區 ===
現今八德區行政範圍的確立，來自於1920年，日本將臺灣十二廳改為五州二廳，設八塊-{庄}-屬新竹州桃園郡{{r|市志政治篇|p=78}}。八塊-{庄}-轄八塊、大湳、小大湳、下-{庄}-子、茄苳溪、霄裡等6個大字{{sfn|施添福|2009|pp=176－178}}。1945年，改為「八塊鄉」，屬新竹縣桃園區。1946年4月，改名「八德鄉」。1950年，調整行政區域並裁撤區署，八德鄉改隸新成立的桃園縣。1995年1月1日，八德鄉改制為「八德市」{{r|市志政治篇|p=78}}。2014年12月25日，桃園縣改制為直轄市，八德市改制為市轄區「八德區」，隸屬桃園市<ref name="八德尋根"/>。

=== 大湳地區都市計劃 ===
八德大湳地區都市計畫區範圍以[[大成國小]]附近大湳市場、民和戲院之舊商圈及廣豐新天地、國賓影城新興商圈等商業區為中心，包括介壽路兩旁，南至大潤發賣場，北至桃園都市計畫界線，總面積約409.27[[公頃]]；目前為八德區人口聚集的主要地區。2016年桃園市政府整併全市33處都市計畫區，將此區整併入桃園都會區都市計畫。

範圍：大福里、大正里、大宏里、大智里、大勇里、大榮里、大義里、大漢里、大千里、大忠里、大慶里、大同里、大成里、陸光里、大和里、大部分（大盛里、大愛里）、部分（大強里、大湳里、大興里、大華里、廣隆里、桃園區中德里）。

=== 八德地區 (擴大) 都市計劃 ===
[[File:八德都市計畫區.png|thumb|250px|八德都市計畫區全景圖；左後[[林口臺地]]及遠處的[[觀音山 (新北市)|觀音山]]；右後為[[陽明山]]]]
[[File:新潤御丰莊園.jpg|thumb|八德擴大都市計畫區的知名最高地標]]
==== 沿革 ====
本特定區原是配合[[高鐵桃園站]]與[[國家衛生研究院 (台灣)|國衛院]]等兩大基礎建設將在該區設立而規劃，惟後來皆未在該區設立。目前則是以八德區公所為中心，1994年起由地方開始規劃，2003年送交[[中華民國內政部|內政部]]審議，經過無數次的溝通協調，擴大都市計畫面積由原來650公頃驟減至164.78公頃（扣除舊市區面積49.16公頃，實際擴大面積115.62公頃）。2009年1月內政部審核通過第一期116公頃的開發計劃案（土地變更），已於2010年初完成，未來還將持續規劃進行第2期、第3期的都市計劃開發案。2016年桃園市政府整併全市33處都市計畫區，將此區與大溪埔頂都市計畫區整合。

==== 規模 ====
範圍：大部分（福興里、瑞豐里）、部分（興仁里、瑞興里）。
===== 第一期 =====
[[八德擴大都市計劃區]]內，目前有二條寬達50米的大道（建德路、豐德路），以及建置長達28公里的寬頻管道，還有[[桃園捷運]]綠線的捷運車站專區，形成環狀的捷運網絡系統，並與大台北捷運系統接軌（目前尚在規劃中）。八德擴大都市計畫廣置公園，瑞興、福興、興仁、瑞豐、瑞德等里都畫設公園用地，還特意保存區內4口水利會大池塘，讓它成為自然生態公園，成為八德區主要特色。還有總長8公里多環區的自行車道。區內西邊還保留2.4公頃作為[[國立中央大學|中央大學]]八德校區。東側豐德路介壽路口增設國道三號大鶯豐德交流道（暫名）可行性評估市政府已於2018年9月送交通部高公局審議。<ref>{{Cite web |url=http://www.tycg.gov.tw/ch/home.jsp?id=9&parentpath=0,1&mcustomize=news_view.jsp&dataserno=201605020004&aplistdn=ou=news,ou=chinese,ou=ap_root,o=tycg,c=tw&toolsflag=Y |title=八德第二交流道可行性研究送中央審議 |accessdate=2018-01-08 |archive-date=2020-05-25 |archive-url=https://web.archive.org/web/20200525190730/https://www.tycg.gov.tw/ch/home.jsp?id=9&parentpath=0%2C1&mcustomize=news_view.jsp&dataserno=201605020004&aplistdn=ou%3Dnews%2Cou%3Dchinese%2Cou%3Dap_root%2Co%3Dtycg%2Cc%3Dtw&toolsflag=Y |dead-url=no }}</ref>
八德擴大都計的第三條大道（園三），路寬40米，本為生活圈六號道路，現更名為「八德區介壽路至建德路新闢道路」。長度約1.7公里，未來會從八德擴大都市計畫建德路、仁德一路口沿仁德一路，穿越建國路、豐田路沿著產業道路，最後再連接介壽路二段六八五巷（伍陽農場）旁，新闢道路會配合捷運綠線土木工程，將會委託捷運施工單位一併施工，預定2019年12月施工，2025年11月完工。

==== 與文化資產的衝突 ====
葉金萬是桃園八塊厝當地人，生於[[清代]][[道光]]21年（1841年），歿於[[台灣日治時期|日治時代]][[昭和]]5年（1930年），享年89歲，是台灣當時著名的建廟老師傅，八德三元宮殿內的木樑及雕飾，古樸典雅，就是出自此名木作大師葉金萬之手。其故居「樹德堂」，原為葉氏祖厝宗祠，就位於三元宮旁；古厝建造於[[咸豐]]4年（1854年），為傳統三合院格局。卻在此次八德擴大都市計劃中，古厝被拆除，夷為平地。<ref>{{Cite web |url=http://www.tonyhuang39.com/tony0531/tony0531.html |title=桃園八德．三元宮．呂氏著存堂．日本神風特攻隊隊長駐所舊址 【Tony的自然人文旅記 】 |accessdate=2012-07-13 |archive-date=2020-10-30 |archive-url=https://web.archive.org/web/20201030215741/http://www.tonyhuang39.com/tony0531/tony0531.html |dead-url=no }}</ref>。

=== 客運轉運站 ===
[[File:八德轉運站.jpg|thumb|250px|和強路上的八德轉運站]]
==== [[八德轉運站]] ====
離國道2號大湳交流道僅400公尺，八德區和強路與和平路口，定位為市區客運及國道客運轉乘站，基地面積1250坪，共設置4席停靠月台、122席機車停車位、3席汽車臨停接送區、2席計程車排班區及17席公共自行車位，提供乘客無縫轉乘其他運具。於2024年2月19日啟用。

==== <span style="color:#888888;">八德豐德轉運站</span> ====
