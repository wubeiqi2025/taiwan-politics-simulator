'''朴子市'''{{NoteTag|「朴子」一名來自[[朴樹]]，「朴」字做樹名時發音為-{zh-tw:ㄆㄛˋ;zh-cn:pò;}-，發音為-{zh-tw:ㄆㄨˊ;zh-cn:pú;}-時為「質-{樸}-」的-{樸}-的通同字<ref>{{cite web |url=https://dict.revised.moe.edu.tw/dictView.jsp?ID=617 |title=朴 |publisher=中華民國教育部 |work=《重編國語辭典修訂本》臺灣學術網路第六版 |date= |accessdate=2025-01-04 |language=zh-tw |archive-date=2023-04-13 |archive-url=https://web.archive.org/web/20230413155912/https://dict.revised.moe.edu.tw/dictView.jsp?ID=617 |dead-url=no }}</ref>。然而作為「朴子市」時，仍發為-{zh-tw:ㄆㄨˊ;zh-cn:pú;}-音<ref>{{cite web |url=https://dict.revised.moe.edu.tw/dictView.jsp?ID=26368 |title=朴子市 |publisher=中華民國教育部|work=《重編國語辭典修訂本》臺灣學術網路第六版 |date= |accessdate=2025-01-04|language=zh-tw }}</ref>。}}，舊稱「樸仔樹腳」，後稱「樸仔腳」，得名自[[朴子配天宮]]<ref>余文儀《續修臺灣府志》：「朴仔腳街，舊為猴樹港街，今更名。」</ref>，前身「朴子鎮」，位於[[臺灣]][[嘉義縣]]西部，嘉義縣海線地區的中心城鎮，是一個因[[媽祖]]而興起的聚落<ref name="history">{{cite web |url=http://puzih.cyhg.gov.tw/html/sec_8.html |title=樸仔腳的故事-嘉義縣朴子市公所全球資訊網 |publisher=朴子市公所 |date= |accessdate=2015-11-01 |archiveurl=https://web.archive.org/web/20150511064643/http://puzih.cyhg.gov.tw/html/sec_8.html |archivedate=2015-05-11 |language=zh-tw }}</ref>，由於地理位置關係而與[[北港鎮 (台灣)|北港鎮]]往來密切。

1945年將[[朴子街]]改制[[臺南縣]][[東石郡|東石區]]朴子鎮，1950年改隸嘉義縣，1992年因[[嘉義縣議會]]遷設於該地，成為嘉義縣治的一部份，改制為縣轄市。在[[高鐵嘉義站]]、[[嘉義BRT]]開通後，往[[嘉義市]]通勤比例逐漸成長，交流愈趨頻繁。

==歷史==
舊名猴樹，[[荷治時期]]《[[熱蘭遮城日誌]]》中即出現「Causieu」，即猴樹（kâu-tshīu）之[[閩南語]]音。[[臺灣清治時期|清領時代]]1747年（[[乾隆]]12年）《重修台灣府志》記載為「猴樹港街」，清乾隆29年《續修台灣府志》則記載：「朴仔腳街，舊為猴樹港街，今更名。」清朝年間，樸仔腳<ref name="history"/>地區僅有數間農舍及數株[[朴樹|樸仔樹]]。樸仔樹蒼翠成蔭，樹下逐漸成為旅途者或居民所休息乘涼好地方。1682年（[[康熙]]21年），林馬從湄洲祖廟迎請媽祖，欲至居住地布袋嘴半月庄供祀，經牛稠溪{{〈}}朴子溪{{〉}}南岸樸仔樹下休息。當地民眾聞訊聚集參拜，並奉神意指示要停住此地，故在此樹下立廟稱為樸樹宮。清乾隆54年（1789年），樸樹宮奉令改為「配天宮」。當地便以媽祖廟為中心，逐漸發展成市鎮，當地因於樸仔樹下建廟，奉祀媽祖而發跡，於是取名「樸仔腳」。指樸仔樹下的意思，「腳」是台語「下」的意思。而[[樸樹]]也因而成為朴子市的市樹。

清治時期各街-{庄}-分屬：
*[[大槺榔西堡]]內之樸仔腳街、下竹圍-{庄}-、雙溪口-{庄}-、大槺榔-{庄}-、小槺榔-{庄}-；
*[[大坵田西堡]]內之應菜埔-{庄}-、崁前-{庄}-、崁後-{庄}-、龜仔港-{庄}-、鴨母藔-{庄}-、吳竹仔腳-{庄}-、新-{庄}-；
*[[白鬚公潭堡]]內之牛挑灣-{庄}-、南勢竹-{庄}-。

1901年11月23日'''樸仔腳抗暴事件'''，黃茂松率眾進攻樸仔腳街官署。<ref>{{Cite web |title=讀冊絕不是簡單的事（二）－樸仔腳事件 |url=https://www.samsiugarden.com/post/%E8%AE%80%E5%86%8A%E7%B5%95%E4%B8%8D%E6%98%AF%E7%B0%A1%E5%96%AE%E7%9A%84%E4%BA%8B%EF%BC%88%E4%BA%8C%EF%BC%89%EF%BC%8D%E6%A8%B8%E4%BB%94%E8%85%B3%E4%BA%8B%E4%BB%B6 |website=三秀園 |date=2026-08-16 |language=zh |last=Un-Hông） |first=傅恩弘（Pòo |access-date=2026-10-20}}</ref> 1911年[[蒜頭糖廠]][[台灣糖業鐵路|運蔗鐵道]][[朴子線]]通車。1911年設立樸仔腳區，隸屬[[嘉義廳]]樸仔腳支廳，管轄[[大槺榔西堡]]內之[[樸仔腳街]]、[[下竹圍]]-{庄}-、[[雙溪口 (嘉義縣朴子市)|雙溪口]]-{庄}-、[[大槺榔 (嘉義縣)|大槺榔]]-{庄}-、[[小槺榔]]-{庄}-、[[下雙溪 (嘉義縣)|下雙溪]]-{庄}-、[[溪墘厝]]-{庄}-；[[大坵田西堡]]內之[[𧃽菜埔]]-{庄}-、[[崁前]]-{庄}-、[[崁後]]-{庄}-、[[龜子港 (嘉義縣)|龜仔港]]-{庄}-、[[鴨母寮 (嘉義縣)|鴨母藔]]-{庄}-、[[吳竹仔腳]]-{庄}-、[[新庄 (嘉義縣朴子市)|新-{庄}-]]、[[馬稠後 (嘉義縣)|馬稠後]]-{庄}-。([[牛挑灣 (嘉義縣)|牛挑灣]]-{庄}-、[[南勢竹]]-{庄}-屬南勢竹區)

[[File:PuzihPrecinctOfChiayiCountyPoliceBureau.jpg|thumb|250px|[[嘉義縣警察局]]朴子分局]]
1920年（大正9年），[[臺灣總督府]]實施州廳－郡市—街-{庄}-三級地方區劃，改樸仔腳為朴子，'''樸仔腳區'''下雙溪、溪墘厝改隸-{[[六腳庄]]}-，馬稠後改隸-{[[鹿草庄]]}-，其餘改制[[朴子街]]隸屬[[臺南州]][[東石郡]]，並為'''東石郡役所'''駐地（今[[中華民國警察分局列表#嘉義縣警察局|朴子警分局]]廳舍）。(牛挑灣、南勢竹屬-{[[義竹庄]]}-)1932年-{[[六腳庄]]}-下雙溪居民因[[朴子溪]]洪水氾濫集體遷村，在'''樸仔腳'''與'''雙溪口'''間重建家園，建成'''新吉-{庄}-'''（新結-{庄}-仔）與'''下寮仔'''。1934年興建朴子水塔，塔高35公尺，至今仍為朴子最顯著的地標。1936年（昭和11年）9月10日東石神社鎮座。（今朴子藝術公園）

[[臺灣戰後時期|戰後]]1945年10月，[[中華民國政府]]接管臺灣，將日治時期的五州三廳改為八縣九省轄市二縣轄市{{r|市志卷之二|p=114}}。12月11日，朴子街改為朴子鎮，屬[[臺南縣]]東石區<ref name="history"/>。1950年10月，將[[嘉義市 (1945年—1950年)|嘉義市]]與嘉義、東石兩區合併設立[[嘉義縣]]，並裁撤區署{{r|市志卷之二|p=114}}，朴子鎮改隸嘉義縣<ref name="history"/>。1962年，朴子鎮將原屬[[義竹鄉]]的梅華村、松華村和南竹村等3個村納入鎮域{{sfn|施添福|2008|p=70}}。1982年7月1日，嘉義市改制為[[嘉義市|省轄市]]，嘉義新縣治所在地選擇跨越[[太保市|太保]]、朴子兩地的台糖東勢寮農場地，其中[[嘉義縣議會|縣議會]]位於朴子鎮內{{r|市志卷之二|p=114}}。1992年6月9日，嘉義縣議會臨時會議提案〈擬將本縣朴子鎮改制為縣轄市〉議決通過，報奉[[臺灣省政府]]。8月24日，臺灣省政府核定提案。9月10日，朴子鎮改制為[[縣轄市]]「朴子市」{{r|市志卷之二|p=115}}。

== 地理 ==
=== 地形 ===
朴子市位於嘉義縣西部，距離[[台灣海峽]]12公里，東接[[太保市]]、[[鹿草鄉]]，西連[[東石鄉]]和[[布袋鎮]]，南毗[[義竹鄉]]，北隔[[朴子溪]]與[[六腳鄉]]相望。地處[[嘉南平原]]西北端，海拔高度平均約為5公尺，整體地勢低而平緩，地層上皆由沖積層所構成，土壤則以砂質壤土及粘土為主{{r|市志卷之一|p=17}}。

=== 氣候 ===
朴子市氣候為[[熱帶季風氣候]]，年平均溫度皆在攝氏20度以上。根據1985年至1994年[[行政院農業委員會臺南區農業改良場|臺南農業改良場]]朴子分場農業氣象站的資料顯示，朴子市的年均溫約在23.6度至26.9度間，最熱月份為7月的30.7度，最冷為1月的18.0度。年平均降雨量則介於1,100毫米至1,900毫米之間，雨季集中於4月至9月{{r|市志卷之一|pp=17－19}}。

戰後初期，1946年朴子市的人口計有30,989人，至1970年代之前由於自然增加的因素，人口持續正成長<ref name="黃"/>。1971年時，朴子市人口達到50,430人，是戰後以來的最高值<ref name="pzhro3146">{{cite web |url=https://puzih-hro.cyhg.gov.tw/cp.aspx?n=3146 |title=人口統計-歷年人口數-朴子市歷年人口數 |access-date=2025-02-03 |publisher=嘉義縣朴子戶政事務所 |language=zh-tw }}</ref>。其後隨著都市化的因素，人口開始外流<ref name="羅"/>。1992年底時朴子市尚有45,018人，至2016年時已下滑至42,585人<ref>{{Cite web |author=吳佳蓉、謝惠伃 |url=https://enews.ccu.edu.tw/%E5%BB%BA%E8%A8%AD%E6%95%B4%E5%90%88%E8%A8%88%E7%95%AB-%E6%9C%B4%E5%AD%90%E5%B8%82%E7%9B%BC%E8%BD%89%E5%9E%8B-9709eae87489 |title=建設整合計畫 朴子市盼轉型 |publisher=中正E報 |date=2017-11-29 |access-date=2020-03-18 |language=zh-tw |archive-date=2020-12-02 |archive-url=https://web.archive.org/web/20201202073221/https://enews.ccu.edu.tw/%E5%BB%BA%E8%A8%AD%E6%95%B4%E5%90%88%E8%A8%88%E7%95%AB-%E6%9C%B4%E5%AD%90%E5%B8%82%E7%9B%BC%E8%BD%89%E5%9E%8B-9709eae87489 |dead-url=no }}</ref><ref name="pzhro3146"/>。根據嘉義縣朴子戶政事務所及嘉義縣政府民政處統計，2025年底朴子市戶數約1.7萬戶，人口約4萬人<ref name="puzih-hro"/>，是嘉義縣海線地區的最大城市<ref name="civil.cyhg"/>。

與嘉義縣其他地區相同，朴子市面臨嚴重[[人口老化]]與[[少子化]]的問題<ref name="ris.gov.tw"/>。朴子市的人口金字塔由戰後初期的等腰三角形，至1970年時已呈現燈籠形。在2010年時，進入高齡社會<ref name="黃"/>，到了2022年2月老年人口達到20%，進入超高齡社會<ref name="ris.gov.tw"/>。2025年底時，朴子市人口的年齡構成中，有11.28%的人口年齡在0至14歲，66.55%是15至64歲人口，65歲以上人口則有22.17%，老化指數約為196.56%<ref>{{Cite web |url=https://puzih-hro.cyhg.gov.tw/News.aspx?n=3143&sms=16080 |title=人口統計-性別年齡人口數-朴子市性別年齡層人口數 |access-date=2025-02-03 |publisher=嘉義縣朴子戶政事務所 |language=zh-tw }}</ref>，是臺灣老年人口比例最高、老化指數最高的縣轄市<ref name="ris.gov.tw"/>。朴子市的性別比例，戰後初期主要為女多於男，在1969年之後則是男多於女<ref name="黃"/>，至2025年底時男對女性別比約為100.13%<ref name="puzih-hro"/>，為嘉義縣最低<ref name="civil.cyhg"/>。

朴子市的人口分布上，早期人口主要集中在市街，之後則是逐漸往東、西與南方等地移動，市街南邊的竹圍里在1950年至2010年間，人口成長超過8倍，是人口遷入的重心所在<ref name="黃"/>。朴子市的朴子、下竹圍、𧃽菜埔、大槺榔及部分的祥和新村等5個聚落是人口集中區，此5個聚落的總人口數，佔全市人口數的一半左右<ref name="羅"/>。除市街地區外，其他各-{里}-由於面積相對較大，人口密度相對偏低<ref name="黃"/>。2025年底時，朴子市內人口最多與最少的里分別是竹圍里與順安里，兩里人口分別為5,033人與235人<ref name="puzih-hro"/>；人口密度最高與最低的里分別是平和里與順安里，兩里人口密度分別為每平方公里11,343人與154人<ref>{{cite web |url=https://puzi.cyhg.gov.tw/cp.aspx?n=9568 |title=觀光導覽-村里導覽 |access-date=2025-01-27 |publisher=嘉義縣朴子市公所 |language=zh-tw }}</ref><ref name="puzih-hro"/>。

=== 市政組織 ===
[[File:PuzihCityOffice.jpg|thumb|250px|舊朴子市公所，已於2021年拆除<ref>{{cite news|url=https://www.chinatimes.com/newspapers/20210327000515-260107?chdtv |author=張毓翎 |title=〈朴子公所舊廳舍將拆除 員工不捨〉|publisher=中國時報 |date=2021-03-27}}</ref>]]
[[File:朴子市日據時代風格警局(光復路).jpg|thumb|朴子分局（原東石郡役所）]]
'''朴子市公所'''是朴子市最高層級的地方[[行政機關]]，在中華民國政府架構中為縣轄市自治的行政機關，同時負責執行縣政府及中央機關委辦事項，朴子市的自治監督機關為[[嘉義縣政府]]。市長由全體市民直接選舉產生，任期為四年，可連選連任一次。朴子市公所並置市政會議，為市政最高決策機構，在市長之下，設有5課4室等9個內部單位及4個附屬機關<ref>{{cite web| language=zh-tw| url=http://puzih.cyhg.gov.tw/content/index.aspx?Parser=1,4,31| title=公所簡介-組織架構-嘉義縣朴子市公所全球資訊網| publisher=朴子市公所| date=| accessdate=2017-04-20| archive-url=https://web.archive.org/web/20170421195118/http://puzih.cyhg.gov.tw/content/index.aspx?Parser=1,4,31| archive-date=2017-04-21| dead-url=yes}}</ref>。

[[嘉義縣朴子市民代表會|朴子市民代表會]]是朴子市的最高[[民意機關]]，代表朴子市全體市民立法和監察市政。市民代表由公民直選選出，任期為四年，可連選連任。朴子市民代表會共有11位市民代表，分別為第一選區5席市民代表、第二選區4席市民代表、第三選區2席市民代表，主席、副主席由11位市民代表互選產生<ref>{{cite web| language=zh-tw| url=http://puzih.cyhg.gov.tw/content/index.aspx?Parser=1,7,53| title=市民代表會-嘉義縣朴子市公所全球資訊網| publisher=朴子市公所| date=| accessdate=2017-04-19| archive-url=https://web.archive.org/web/20170421195042/http://puzih.cyhg.gov.tw/content/index.aspx?Parser=1,7,53| archive-date=2017-04-21| dead-url=yes}}</ref>。

[[臺灣嘉義地方法院]]是朴子市的第一級[[司法機關]]，負責初審的司法案件，並在市內設有朴子簡易庭，為嘉義海線地區小型訴訟的申訴機關。

=== 行政區 ===
現今朴子市行政範圍的確立，來自於1962年調整行政區域，將原屬義竹鄉的松華村、梅華村、南竹村等3村劃入朴子鎮{{R|縣志政事志|p=37}}。1992年7月1日，朴子鎮改制為「朴子市」{{r|市志卷之二|p=115}}。

1979年朴子國小少棒隊奪得全國少棒冠軍、遠東區少棒冠軍及[[世界少棒大賽]]冠軍。
